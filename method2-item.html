05 · Direct-cost pricing provisions

Pricing assumptions start here. They help fix an ideal selling price and never change Actual COGS.

UUWP rule: When leftovers exist, BOBS automatically uses the actual leftover percentage. When 100% is sold, the UUWP default allowance above is used (default 5%).

UUWP is a pricing allowance only; it does not change Actual COGS. Markup is not profit margin.
