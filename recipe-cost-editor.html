How to test this page — Idli recipe (steps 6–12)
  1. From the Idli item, open Idli – recipe & cost. Expected: Intended output quantity is 360 on the left.
  2. On the right inspect the BOBS Standard Recipe. When the Google standard exists it is used first; if it is unavailable, BOBS falls back to the audited market-reference library. The historical Recipe Master is backup only and is never used as a costing fallback.
  3. Check Reference recipe yield. For Idli the current researched reference uses a 120-piece commercial batch, but the page must state that equipment is also sold in other capacities and 120 is not a universal standard.
  4. First review Reference cooked portion weight (g) and its source. Then choose Intended cooked portion weight (g); select Custom weight in the list before entering grams. Switching to reference size or a listed weight clears and disables the custom box. Portion size and steamer capacity are separate from the culinary recipe yield.
  5. Click Calculate quantities from reference beside the portion choices. Read the completion message and chosen portion size there, then use View calculated quantities and Save. Check rice, urad, poha, all other ingredients, fuel quantities and rates. Recalculate after changing target or reference.
  6. If you try to tick the checkbox or save before calculating, read the portion-review dialogue, choose Review portion sizes, check both weights, then calculate. After a successful click on Calculate, review the result and tick I checked reference yield, portion assumptions, ingredient rates and energy use only after review.
  7. Click Save outlet production recipe & return to item. Wait for “Outlet recipe saved and verified”, then return to the Idli item. If a prerequisite or save fails, stop and correct it before proceeding.

Next: return to the item editor for step 13. Saving this outlet recipe does not replace the Google BOBS Standard Recipe or the audited market-evidence/calibration records.
