Ingredient editor: add any missing ingredient or topping, enter quantity, unit and purchase rate. BOBS recalculates recipe batch cost and cost per yield unit immediately. Changes are written only when you press Save recipe.

Standard costing model

pro-rata + yield

Recipe batch cost = Σ ingredient cost. Unit cost = batch cost ÷ standard yield. Actual production scales the standard recipe pro-rata. For ingredients with trimming/preparation loss, future yield % can be applied to derive usable-cost rates. Sub-recipes/condiments are costed once and reused in parent products.

All produced items and their components use this same Recipe Master costing structure. No separate condiment costing model is required.
