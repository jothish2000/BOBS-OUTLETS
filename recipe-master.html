Current planning basis: small opening batches. Recipes can scale later; the standard batch is deliberately conservative for a first-time outlet.

Costing rule: LPG/electricity used for the batch is stored as a costed recipe input, so energy is included in Recipe Master COGS instead of being shown only as a note.

Migration safety: before BOBS upgrades an older Recipe Master to the current standard, it writes a Google recovery snapshot. Existing local ingredient rates are preserved where the same ingredient already exists. Idli ingredient quantities/yield are preserved; only missing timing/energy is added.

Standard costing model

ingredients + fuel + yield

Batch COGS = food/raw-material inputs + directly attributable batch energy. Unit COGS = batch COGS ÷ standard yield. Labour remains outside Actual COGS and is handled by Workload/Staffing and outlet economics.

Planning rates are editable. The current seed uses commercial LPG ₹2,916.50 / 19 kg = ₹153.50/kg and the outlet EB planning rate ₹11/kWh. Replace ingredient/energy rates with actual invoices when available.
