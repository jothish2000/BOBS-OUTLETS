First-time recipe library setup

What is this page for?

This page is for the person setting up BOBS for the first time, when its shared recipe library has not yet been saved in Google Sheets. It saves the prepared market references, BOBS quantity adjustments (calibration), and BOBS standard recipes so BOBS can use them.

What does “publish” mean here? It means saving this prepared recipe information into BOBS’s Google Sheets. It does not mean posting recipes publicly on the internet or doing a new Google search.

  1. For everyday recipe work: return to your open Item Editor or Recipe cost editor tab. Review ingredients, change the required quantity, or edit your outlet recipe there. You do not need this first-time setup page for those tasks. Keep any unsaved edits in that tab.
  2. For first-time setup: this page checks for saved records. Only when the required recipe sections are empty and the historical recipes can be read will it offer the first save. Review the comparison before saving. The save creates a historical backup, saves the three recipe sections, and checks them again.
  3. If records already exist: do not repeat the first save. Return to your recipe work. To correct the shared BOBS standard, ask the person maintaining BOBS to compare the proposed correction with the saved version, back it up, and save an approved revision. This page cannot make that revision; ordinary outlet recipe editing is a separate action.

The old Recipe Master is kept as historical backup. It is not used as the operational fallback recipe.
