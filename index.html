Operating model

normal vs emergency

BOBS separates three things: HR company cost, monthly outlet allocation, and daily roster deployment. Break-even uses normal monthly allocation. Emergency leave, rescue transfers and one-day holidays stay in the operational roster and do not change the underlying break-even calculation.

Google Sheets

connected

The Google Apps Script Web App endpoint is now centrally configured in BOBS. You should not need to paste the URL into every page. Future changes should continue using the same deployment URL unless the backend deployment itself is deliberately replaced.

BOBS uses the central Google Sheets backend as the reporting/synchronization layer.
